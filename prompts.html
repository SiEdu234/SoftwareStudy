Todo en Uno · Salida .JSON Prompt Maestro Unificado (PDF / Word / Slides / Código / Apuntes)
Preguntas: 
Actúa como un profesor universitario y examinador académico experto.
Analiza exhaustivamente el material adjunto o proporcionado (ya sea PDF, documento Word, presentación PowerPoint/Slides, apuntes de clase o código fuente) y genera un banco de preguntas riguroso para la plataforma "Estudien Vagos".

FORMATO DE SALIDA OBLIGATORIO (ARCHIVO .JSON):
1. Genera y entrégame el resultado directamente como un ARCHIVO DESCARGABLE con extensión `.json` (por ejemplo: `cuestionario.json`) codificado en UTF-8.
2. Si tu entorno no permite adjuntar archivos descargables, responde ÚNICAMENTE con el bloque JSON válido puro, sin introducciones, saludos ni texto fuera del JSON.

REGLAS PEDAGÓGICAS Y DE CONTENIDO:
1. Cobertura total: Distribuye las preguntas a lo largo de todo el material (inicio, desarrollo, casos prácticos y conclusiones), evitando concentrarte solo en las primeras páginas.
2. Adaptación automática según el material:
   - Si son Diapositivas/PPT o apuntes breves: reconstruye el contexto teórico completo detrás de cada viñeta o diagrama.
   - Si es PDF o Word teórico: evalúa comprensión profunda, relaciones causa-efecto y aplicación práctica.
   - Si incluye Programación / Software / Código: incluye fragmentos de código usando bloques Markdown (```lenguaje ... ```) dentro de "text", activa `"isCode": true`, y evalúa salidas por consola, detección de bugs o complejidad.
3. Variedad de tipos ("type"):
   - "single": Selección única (4 opciones, solo 1 con `"isCorrect": true`).
   - "multiple": Selección múltiple (4 opciones, 2 o más con `"isCorrect": true`).
   - "boolean": Verdadero o Falso (2 opciones: "Verdadero" y "Falso").
4. Distractores realistas: Las opciones incorrectas deben ser verosímiles y basadas en confusiones típicas de examen.
5. Feedback formativo: En el campo "feedback", explica claramente por qué la respuesta correcta es válida y por qué se descartan las demás.
